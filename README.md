# Petra

Clipboard manager for Linux.

## Features

- Keyboard navigation
- Filter grouping (text, images, links, commands)
- Emoji insertion
- Image preview
- Linux command recognition
- Pin items
- Pin window
- Clear items

## Installation

In a terminal, run these commands in the project folder:

To build the Flatpak (for testing and direct installation):
```bash
./build-flatpak.sh
```

To create a distributable .flatpak file:
```bash
./make-flatpak.sh
```

To install the newly created Flatpak:
```bash
./install-flatpak.sh
```
